# AWS Serverless - Ferrideck

Backend principles for this project. The maintainer is **learning AWS**; explain
the reasoning behind each architectural choice.

## Non-negotiable rules

- **RDS is never public.** It lives in a private subnet; only the Lambda (inside
  the VPC or via RDS Proxy) reaches it. Never suggest opening the security
  group to the internet, even "temporarily for testing".
- **No secrets in the desktop app.** ElevenLabs and database credentials exist
  only in Lambda environment config, sourced from AWS Secrets Manager or SSM
  Parameter Store. The desktop app authenticates to the API, nothing else.
- **S3 access is via pre-signed URLs** generated by the Lambda, with short
  expiration (minutes). The bucket blocks all public access.
- **IAM: least privilege.** Each Lambda role gets only the exact actions and
  resources it needs (e.g. `s3:GetObject` on one prefix, not `s3:*`).

## Stack conventions

- Lambdas are written in Rust with `cargo-lambda`; deploy with
  `cargo lambda deploy` or via GitHub Actions.
- Prefer Lambda **Function URLs** over API Gateway while the API is simple
  (cheaper, less configuration); revisit if auth/routing needs grow.
- Database migrations are SQL files in `migrations/`, applied with `sqlx
  migrate` - never hand-edited schema changes in the console.
- Sync endpoint contract: client sends changes since `last_sync_at`, receives
  server changes since same timestamp; conflicts resolve last-write-wins by
  `updated_at`.

## Cost awareness

This is a personal project - always mention the cost implication of a
suggestion. Defaults: smallest RDS instance or consider stopping it when idle,
Lambda ARM (Graviton) architecture, S3 lifecycle rule to Infrequent Access for
old audio. Flag anything that could silently generate cost (NAT Gateway,
provisioned concurrency, RDS Proxy).

## Local development

```bash
cargo lambda watch                    # run the Lambda locally
cargo lambda invoke --data-file event.json
aws s3 presign s3://bucket/key --expires-in 300   # test pre-signed URLs
```
